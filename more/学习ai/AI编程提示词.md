# AI 编程提示词（Prompt）大全

## 一、代码生成

### 基础代码生成
```
请用 Python 实现一个函数，功能为：
- 输入：一个整数列表
- 输出：列表中所有偶数的平方和
请写出完整代码并附上注释。
```

### 多语言转换
```
将以下 Python 代码转换为 Go 语言，保持相同的功能和逻辑：

[粘贴代码]
```

## 二、代码审查与优化

### 代码审查
```
请审查以下代码，指出潜在的 bug、性能问题和代码风格问题：

[粘贴代码]
```

### 性能优化
```
请优化以下代码，使其在时间和空间复杂度上更高效：

[粘贴代码]
```

## 三、调试排错

### Bug 定位
```
我的代码出现了以下错误，请帮我分析可能的原因并给出修复方案：

错误信息：
[粘贴错误信息]

相关代码：
[粘贴代码]
```

### 单测生成
```
请为以下函数编写单元测试，覆盖正常情况和边界情况：

[粘贴函数]
```

### 系统设计

```
- 系统架构图（文字描述）
- 核心接口设计
- 数据库表结构
- 关键技术选型
```

### 代码重构
```
请重构以下代码，提升其可读性和可维护性：

[粘贴代码]
```

## 五、提示词技巧

| 技巧 | 说明 |
|------|------|
| 明确角色 | "你是一位资深 Python 工程师..." |
| 给出上下文 | 提供背景信息、技术栈、约束条件 |
| 指定输出格式 | "以 Markdown 表格形式输出" |
| 分步骤 | "第一步...第二步..." |
| 提供示例 | Few-shot 示例有助于提升输出质量 |
| 迭代优化 | 不满意时追加指令逐步调整 |

## 六、常用模板

### 万能模板
```
角色：你是一位[领域]专家
任务：[具体要做什么]
输入：[提供的内容]
要求：
1. [要求一]
2. [要求二]
3. [要求三]
输出格式：[期望的格式]
```
